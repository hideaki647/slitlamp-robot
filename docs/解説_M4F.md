# 解説 M4-F：両眼切替（「右眼へ／左眼へ」の指示で眼を移る）

実施：2026-10-20　／　計画：[[M4計画案_F_両眼切替]]　／　関連：[[解説_M3]]（§12 左眼）・[[解説_M4A]]・[[M4計画案_一覧]]

## 0. ひとことで言うと
生徒AIに、画像に加えて「**右眼へ／左眼へ**」という**指示**を入力し、片眼に合わせた状態から反対の眼へ移って合わせ直せるようにした。**指示つきの生徒は、右眼→左眼・左眼→右眼のどちらも100%成功し、移る速さは先生とほぼ同じ（約2.3秒）だった。** 指示の無い生徒は、今いる眼から動かず0%だった。

## 1. なぜ指示が要るのか
- 両眼の間は約64mmで、細隙灯カメラの視野（横約52mm）より広い。**片眼に合わせた状態では、反対の眼は画面に写らない。**
- 画像だけでは「どちらの眼へ行くか」が決まらない。実際の診察で「次は左眼」と声をかけるように、**指示**（0＝右眼、1＝左眼）を生徒に渡す。
- 生徒に渡すのは指示だけで、目標の眼の位置（特権情報）は渡さない。
- このような、目標を入力として受け取る方策を **goal-conditioned policy（条件付き方策）** という。ロボットに「何をしてほしいか」を伝える入口の例。

## 2. 作ったもの
### 2.1 環境（`sim/env.py`）
| 設定 | 内容 |
|---|---|
| `start="switch"` | 反対の眼の近く（±5mm）から始める＝反対の眼に合わせた状態から移る |
| `ipd_mm=(56, 72)` | 両眼の間の距離を56〜72mmでばらつかせる（今までは64mm固定）。決め打ちで「64mm動けばよい」とならないようにする |
| `eye_mode="both"` | 目標の眼を患者ごとにランダムに決める（お手本の収集用） |
| `set_goal(eye)` | 診察の途中で目標の眼を変える（動画用） |
| `env.goal` | 生徒に渡す指示（0＝右眼、1＝左眼） |
- これらの乱数は患者の乱数と分けたので、使わないときは今までとまったく同じ患者・開始位置になる。

### 2.2 生徒の脳（`learning/model.py`）
```
画像 → CNN → 空間ソフトマックス（特徴点の座標 32個）
                                  ＋ 指示（右眼／左眼の one-hot、2個）→ 全結合 → 指令 (Δx, Δz)
```

### 2.3 お手本（`learning/collect_demos.py --switch`）と学習
| データ | 内容 | 組数 |
|---|---|---|
| 右眼のお手本（M2） | 右眼の近くから合わせる。指示＝右眼 | 3.6万 |
| 左眼のお手本（M3 §12） | 左眼の近くから合わせる。指示＝左眼 | 3.6万 |
| **切替のお手本（新規）** | 反対の眼から移る。目標はランダム、両眼の間の距離は56〜72mm、1人4秒 | **6万**（1,500人、約10分で収集、先生は100%到達） |
- 合計13.2万組で25周学習（約43分、`checkpoints/bc_goal.pt`）。確認用データでの先生とのずれは0.047mm。

### 2.4 比べた方式
| 方式 | 内容 |

## 4. 分かったこと
1. **指示を1つ加えるだけで、画像だけでは決まらない課題が解けた。** 指示の無い生徒は、今いる眼に合わせたまま動かない（0%）。
2. **移る速さは先生と同じ。** 1回最大3mmの制限があるので、64mm前後の移動に約2.2秒かかる。先生も生徒も、遠いうちは毎回3mmずつまっすぐ進んでいた。
3. **心配していた「元の眼に引き戻される」は起きなかった**（最初に逆へ動いた割合0%）。移り始めは、まだ元の眼が画面の中央に写っているが、指示が「反対の眼へ」なら離れていくことを学べていた。
4. **従来型（決め打ち移動＋モジュール型）も100%だった。** 両眼の間の距離のずれ（±8mm）は、移動後の視野（±26mm）に収まるので、モジュール型で合わせ直せる。ただし、移動の後半は目標を見ずに進むので約0.2秒遅く、最終誤差はモジュール型の精度（0.15mm）にとどまる。
5. **指示つきの生徒は、その場で合わせる精度も落ちなかった**（0.05〜0.07mm）。1つの生徒で「合わせる」と「移る」の両方ができる。

## 5. 残る課題・発展
- 両眼の間がもっと広い（または視野がもっと狭い、倍率が高い）と、移った先で目標の眼が視野に入らず、従来型の決め打ち移動は失敗するはず。生徒は移る途中の画像（鼻根部など）も手がかりにできるので、差が出る可能性がある。
- 照明を眼ごとに耳側へ振る案（[[M4計画案_照明を眼ごとに耳側へ振る]]）と組み合わせると、移るときに照明アームが振れる様子も動画で見せられる。
