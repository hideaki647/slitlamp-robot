# ジョイスティック操作の仕組み（細隙灯ロボット）

M0〜M3 に分散していたジョイスティックの説明を1か所にまとめたもの（2026-10-17 時点）。
関連：[[解説_M0]]・[[解説_M1]]・[[解説_M2]]・[[解説_M3]]・[[進捗まとめ_M0-M1]]

## 0. ひとことで言うと
**ロボットアームがジョイスティックを握り、「傾ける」「回す」の2つの操作で細隙灯を動かす。** 傾けると本体が左右・前後に、回すと鏡筒が上下に動く。実際の細隙灯（Haag-Streit型など）と同じ操作方法。

## 1. 実機の操作との対応
| 実機での操作 | 細隙灯の動き | このシミュレータ |
|---|---|---|
| ジョイスティックを左右に倒す | 本体が左右に動く | `js_roll` → `lamp_x` |
| ジョイスティックを前後に倒す | 本体が前後に動く（ピント合わせ） | `js_pitch` → `lamp_y` |
| ジョイスティックを軸まわりに回す | 鏡筒が上下する | `js_spin` → `lamp_z` |
| 台ごと手で滑らせる（粗動） | 本体が大きく動く | **省略**（傾き角＝位置に一本化） |

## 2. 部品の配置（`models/scene.xml`）
```
lamp_base（基台、机の上 z=0.75）   joint: lamp_x（左右 ±70mm）, lamp_y（前後 ±40mm）
 ├ joystick（基台の手前 9cm、支点の高さ z≈0.79）
 │    joint: js_pitch（前後 ±20°）, js_roll（左右 ±25°）, js_spin（軸回転 ±360°）
 │    └ ノブ（支点から11cm上、z≈0.90）  site: js_grip ← アームの手がここを握る
 └ lamp_column（支柱）  joint: lamp_z（高さ ±30mm）
      └ microscope（鏡筒）  camera: slit_cam（細隙灯カメラ）
```
- ジョイスティックは**基台に付いている**ので、倒して本体が動くと、ジョイスティックごと動く。
- ジョイスティックは約30gと軽い。計算が不安定にならないよう、見かけの慣性（`armature=0.05`）と粘り（`damping=0.5`）を付けている（M1のつまずき参照）。

## 3. 連動の仕組み（連動拘束 `<equality>`）
ジョイスティックの角度と本体の位置を、「本体の位置 ＝ 係数 × 角度」というルールでつないでいる。実機ではリンク機構や高さ調整のネジが、この役をしている。

| 名前 | ルール | 係数 | 具体例 |
|---|---|---|---|
| `link_x` | 本体の左右 lamp_x ＝ **0.15** × 左右の傾き js_roll | 0.15 m/rad | 10°倒すと **26mm** |
| `link_y` | 本体の前後 lamp_y ＝ **−0.15** × 前後の傾き js_pitch | −0.15 m/rad | 奥へ倒すと奥へ |
| `link_z` | 鏡筒の高さ lamp_z ＝ **0.00318** × 軸の回転 js_spin | 0.00318 m/rad | 半回転（180°）で **10mm** |

- **符号の決め方（右ねじの法則）：** y軸まわりに＋に回すと、ノブの先は＋x（検者から見て右）へ倒れる → 本体も右へ。どの軸も「ノブを倒した向きに本体が動く」ように符号を合わせた。回転は、上から見て反時計回り（＋）で鏡筒が上がる。
- 拘束をしっかり効かせるため、`solref="0.004 1"`（拘束の反応の速さ）を設定。柔らかすぎると比が 0.15 にならない（M1のつまずき）。

### 実際に動かせる範囲（`sim/slitlamp_api.py`）
| | ジョイスティック | 本体 |
|---|---|---|
| 左右 | ±24°（可動範囲±25°の少し内側、`ROLL_MAX`） | **±62.8mm**（`X_MAX`） |
| 高さ | ±350°（可動範囲±360°の少し内側、`SPIN_MAX`） | **±19.4mm**（`Z_MAX`） |
| 前後 | 使っていない（0°に固定） | ピントは固定 |

- 左右の範囲は M2 で ±20° → ±25° に広げた（開始位置を大きくずらすため）。
- 両眼の瞳孔は ±32mm、頭のずれ ±10mm、開始のずれ ±15mm なので、左右は最大約57mmまで使う。

## 4. 指令から動きまでの流れ
生徒AI（または先生）が0.1秒ごとに出すのは、「本体をあと Δx, Δz [mm] 動かせ」という**差分**。
```
① 指令 Δx, Δz（最大 ±3mm）
   ↓ 目標位置に足し込む（env.step、範囲で打ち切り）
② 本体の目標位置 (x, z)
   ↓ 係数で割る（lamp_to_joystick）
③ ジョイスティックの目標角 roll = x / 0.15、spin = z / 0.00318
   ↓ ノブの位置と向きを計算（knob_pose）。本体ごと動く分も含める
④ ノブの目標の位置・向き
   ↓ 逆運動学 IK（arm_ik.py）。前回の答えから30回くり返して解く
⑤ アーム6関節の目標角 → 位置制御モーター（kp=250, kv=6）
   ↓ 物理シミュレーション（手とノブは weld で一体）
⑥ ジョイスティックが傾く・回る → 連動拘束で本体が動く
```
- 0.1秒の中で、指令を5分割してなめらかに動かす（急に動かすとアームが振動する）。
- **1回の指令でのジョイスティックの動き：** 左右3mm → 傾き約 **1.1°**、高さ3mm → 回転約 **54°**。高さ8mmずれていれば、合計で約144°回す。
- 指令は「本体の差分」なので、生徒は画像だけで決められる（細隙灯の絶対位置は画像から分からない）。

## 5. アームの握り方と回し方
### 握る（weld）
- 指と摩擦で握る計算は不安定なので、手とジョイスティックを **weld（溶接）** で一体にした。
- 手順（`grasp`）：IKで手をノブに置く → 「手から見たジョイスティックの相対姿勢」を記録 → weld を ON。
- 毎回「握った状態」から始める（近づいて握る動作は省略。レポートに明記する）。
- 手とノブのずれは最大 0.15mm 程度。

### 傾ける・回すのに使う関節
| 関節 | 主な役割 |
|---|---|
| a_yaw（土台の旋回）・a_shoulder（肩）・a_elbow（肘） | ノブの位置を合わせる（倒すとノブの先が横に動く） |
| a_wrist_pitch・a_wrist_dev（手首の曲げ・横曲げ） | 倒したノブの傾きに手の向きを合わせる |
| **a_wrist_roll（手首の回転）** | **ノブを回す＝高さを変える** |

- 6関節あるのは、手先の「位置3つ＋向き3つ」を合わせるため。5関節では、左右に倒したときに手とノブが引っ張り合った（M1）。

### 手首でハンドルを回すときの注意（M3で修正）
- 手は下向き、ノブの軸は上向きで向かい合っているので、**手首の回転はハンドルと逆向き**になる（手首の角度 ≒ −ハンドル角 ＋ 一定のずれ）。
- 向きだけを見るIKには、手首を**1回転（360°）ずらした解**も同じに見える。握るときに「1回転ずれた解」を選ぶと、手首が可動範囲の端に寄り、ハンドルを100°ほど回しただけで限界（当時 −270°）に当たった。左眼の実験で、先生が1人だけ高さを合わせられなかった原因。
- **修正（10/17）：**
  1. 握るとき、ハンドル0°の姿勢から連続につながる手首の角度を選ぶ（`sim/slitlamp_api.py` の `grasp`）。
  2. 手首の可動範囲を ±270° → ±360° に広げた（実際の産業用ロボットの手首は±360°以上が多い）。
  3. IKの出発点が既に正解のとき、可動範囲の確認を飛ばしていたバグを直した（`sim/arm_ik.py`）。
- 結果：先生は両眼で成功率100%、最終誤差 0.024 → 0.008mm。左右±60mmかつ高さ±19mmの四隅だけは手首が届かないが、実際の眼の位置では使わない範囲。

## 6. 簡略化した点（レポートに明記する）
| 実機 | このシミュレータ |
|---|---|
| 大きな移動は台ごと手で滑らせ、傾きは微調整 | 傾き角＝位置に一本化 |
| ピント合わせ（前後）も操作する | 前後は固定（M4候補「ピント合わせ」） |
| 指で握って操作し、持ち替えもする | weld で常に一体、持ち替えなし |
| 回転量・上下量は機種ごとに決まっている | 半回転で10mm（実機の感覚に近そうな値として設定） |

## 7. 係数を変えるには
左右の係数（0.15）・高さの係数（0.00318）は、**2か所を同じ値にそろえて**変える。
1. `models/scene.xml` の `<equality>`：`link_x` / `link_z` の `polycoef` の2番目の数
2. `sim/slitlamp_api.py`：`K_XY` / `C_Z`

- 例：高さを「1回転で10mm」にしたいなら、10mm ÷ 2π ＝ 0.00159 m/rad。この場合、高さの範囲は±350°で±9.7mmに狭まるので、`SPIN_MAX` か手首の可動範囲も見直す必要がある。
- 係数を変えたら、`scripts/m1_demo.py` で連動の比を確認し、M2のお手本・M3の学習はやり直す（指令とジョイスティックの関係が変わるため）。
